# tanstack-ai-expiriments

Collaborative chat experiments. Each implementation is its own GitHub repository, linked from this parent as a git submodule.

## Clone

```bash
git clone --recurse-submodules https://github.com/grmkris/tanstack-ai-expiriments.git
```

If you already cloned without submodules:

```bash
git submodule update --init --recursive
```
